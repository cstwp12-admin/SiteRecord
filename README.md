# SiteRecord — Android pilot

Open https://cstwp12-admin.github.io/SiteRecord/ in Android Chrome.

Offline field notes, photographic evidence and supporting PDF/Word reports for inspectors, engineers and site personnel. This repository hosts the reviewed application build, not notebook records.

Start with the synthetic training example. Wait for **Application available offline**, then try camera/gallery capture, draft recovery, airplane-mode capture, report downloads, and backup/event transfer. Appearance offers Light, Dark and System. Reports retain a white print layout.

Records stay in browser storage. Keep downloaded backups separately. Work on one device at a time and use reviewed event packages for phone/laptop handover; there is no live synchronisation.

This is a pilot, pending physical Android acceptance. Representative PDF/Word outputs were checked locally. Prepared 18 November 2026. Package SHA-256: `3970b66ad34d69af760cd9494b11c0121c4ddfa18b7e4cdd9e0180eaa898a860`.
