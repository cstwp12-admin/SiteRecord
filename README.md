# SiteRecord — Field observation pilot

Open https://cstwp12-admin.github.io/SiteRecord/ in Android Chrome.

Offline field notes, photographs and PDF/Word observation reports for inspectors, engineers and site personnel. This repository hosts application build files, not notebook records.

## Phase 4.1 — Photo annotation

While editing a finding, choose **Annotate a copy** under a photo. Use arrows, rectangles, circles/ovals or text; adjust unsaved marks with Undo/Redo, selection and movement controls. **Save marked copy** adds a separate flattened PNG. Original photos and captions stay unchanged. To correct baked-in marks later, return to the unmarked source and create another copy.

In Reports, expand **Photographs included in this report** to choose originals, marked copies or both. Saved copies survive normal backups and reviewed phone/laptop event handover. Drawing operations are not autosaved: save the marked copy before leaving the editor. Copies are report-sized, up to1600px; no calibrated measurements or redaction are provided.

Start with the synthetic training example and wait for **Application available offline**. If an update is offered, save/close any editor before **Update & reload**. Appearance offers Light, Dark and System. Printed reports stay white.

Records stay in browser storage. Keep downloaded backups separately. Work on one device at a time and use reviewed event packages for handover; there is no live synchronisation. Actual Android annotation acceptance remains pending.
